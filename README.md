## Project Description
This project develops a machine-learning-based Network Intrusion Detection System using the NSL-KDD benchmark dataset. It classifies network connections into Normal, DoS, Probe, R2L and U2R categories.

## Dataset
NSL-KDD dataset:
https://www.unb.ca/cic/datasets/nsl.html

Public dataset repository:
https://github.com/jmnwong/NSL-KDD-Dataset

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Setup / Run Instructions
1. Install Python.
2. Install the required libraries:
```bash
pip install -r requirements.txt
```
3. Open the Jupyter Notebook:
```bash
jupyter notebook
```
4. Open `Ishwar_Dnyaneshwar_Gaikar_ML_Network_Intrusion_Detector.ipynb`.
5. Run all cells from top to bottom.
6. The notebook downloads the dataset automatically and generates the model results and visualizations.

## Key Information
The project compares Logistic Regression and Random Forest models using accuracy, precision, recall and F1-score. It also generates a confusion matrix and Random Forest feature-importance visualization.
